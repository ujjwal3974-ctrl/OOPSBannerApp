# 🚀 OOPS Banner App (UC1 – UC8)

## 📌 Overview

A Java console project that evolves from simple output to a modular, scalable **OOP-based banner generator** displaying **"OOPS"** using `*`.

---

## 🎯 Objective

Print "OOPS" in banner format while improving code step-by-step using better design practices.

---

## 📂 Use Cases Summary

* **UC1:** Basic print using `System.out.println`
* **UC2:** Banner using `*` (multi-line output)
* **UC3:** Store patterns using arrays
* **UC4:** Use loops for dynamic printing
* **UC5:** Inline array initialization (hardcoded)
* **UC6:** Static methods for each character (modular)
* **UC7:** Class-based design (encapsulation, objects)
* **UC8:** HashMap for pattern storage (scalable & efficient)

---

## 🏗️ Final Approach (UC8)

* Store patterns in `HashMap<Character, String[]>`
* Input word → fetch patterns → render using loops

---

## ▶️ Run

```bash
javac UC8_OOPS_Banner_HashMap.java
java UC8_OOPS_Banner_HashMap
```

---

## 🔧 Key Concepts

* Arrays & Loops
* Functions (Static Methods)
* OOP (Class, Object, Encapsulation)
* Collections (`HashMap`)
* StringBuilder

---

## 🚀 Conclusion

Project shows how simple code can be improved into a **clean, modular, and scalable OOP solution**.
